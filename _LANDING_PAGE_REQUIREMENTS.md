# Landing Page Requirements

Reference document for building high-converting app landing page based on analysis of SwipeFile template and Cal AI (calai.app).

---

## Core Principle

**"Keep things stupid simple"** - every section guides the user one step closer to clicking the CTA (Download/Sign Up).

---

## Required Sections (in order)

### 1. Header / Navigation
- Logo on the left
- Minimal navigation (max 3-4 links)
- CTA button on the right (Download / Get Started)
- Mobile hamburger menu

### 2. Hero Section
**Most important section - determines if user stays on page**

| Element | Description |
|---------|-------------|
| **Headline** | Clear value in max 8 words. Format: "[Action] your [thing] with [method]" |
| **Subheadline** | 1-2 sentences explaining how it works |
| **Primary CTA** | One main button (Download / Start Free Trial) |
| **Secondary CTA** | Optional link (Learn More / Watch Demo) |
| **Hero Image/Video** | App mockup or product demo |
| **App Store Badges** | iOS + Android badges if it's an app |

**Cal AI Example:**
> "Meet Cal AI - Track your calories with just a picture"

### 3. Social Proof Bar (optional, below Hero)
- User count: "Loved by 5M users"
- Rating: "4.9 rating"
- Logos of known companies/media

### 4. Features Section
**Showcase 3-4 main features**

**Presentation styles:**
- Carousel with interactive cards (Cal AI style)
- Or: 2x2 grid / 3 columns
- Each feature: icon + title + description (max 2 sentences)
- Phone mockup showing the feature

**Rule:** Benefits > Features
- ❌ "AI-powered image recognition"
- ✅ "Track calories with just a photo"

### 5. How It Works (optional)
3 steps showing the process:
1. Download the app
2. Take a photo / Do action
3. Get results

### 6. Testimonials / Social Proof
**Building trust**

| Type | Usage |
|------|-------|
| Influencer quotes | With photo and name |
| User reviews | 3-4 short quotes |
| Rating badges | "100k+ 5-star reviews" |
| Media logos | "As seen in..." |

### 7. Benefits Section (Why Choose Us)
- 3-4 bullet points with benefits
- Icons + short descriptions
- Can include comparison vs competitors

### 8. FAQ Section (before final CTA)
**Reduces objections before conversion**

- 5-7 most common questions
- Accordion style (click to expand)
- Questions about: pricing, security, how to start, differences vs competition

### 9. Final CTA Section
**Last chance for conversion**

- Repeat main headline or variant
- Same CTA button as in Hero
- Optionally: "Start your free trial"
- App store badges

### 10. Footer
- Logo
- Links: Privacy Policy, Terms of Use, Support
- Social media icons
- Copyright

## Design Patterns

### Color Scheme (Cal AI reference)
```
Primary: Black (#000000)
Background: White (#FFFFFF)
Text: Gray scale (gray-200, gray-300, gray-800)
Accent: Minimal - one color for CTA
```

### Typography
```
Headings: Bricolage Grotesque / Inter (bold, variable)
Body: Inter
Sizes: Mobile .875rem → Desktop lg/xl
Opacity: 70% for descriptions
```

### Spacing & Layout
- Max width: 1200-1400px for content
- Sections: large padding (py-16 to py-24)
- Mobile-first responsive

### Animations (subtle)
- Fade transitions (150ms)
- Smooth scroll
- Hover states on buttons/cards
- Optional: scroll-triggered animations

---

## CTA Strategy

| Location | CTA Type |
|----------|----------|
| Header | Button (secondary style) |
| Hero | Primary button + App badges |
| After Features | Inline CTA |
| Final Section | Full-width CTA block |

**Rule:** One main conversion goal (Download / Sign Up / Start Trial)

---

## Mobile Considerations

- Hamburger menu
- Stacked layout
- Touch-friendly buttons (min 44px)
- Reduced content density
- Bottom sticky CTA (optional)

---

## Content Checklist

- [ ] Headline < 8 words, clear value
- [ ] Subheadline explains "how"
- [ ] Social proof with numbers
- [ ] 3-4 features with benefits (not features)
- [ ] Testimonials with real people
- [ ] FAQ answering objections
- [ ] Consistent CTA throughout the page
- [ ] App store badges (if app)

---

## What NOT to Do

- ❌ Too many CTAs (one main goal)
- ❌ Feature dump without context
- ❌ Generic stock photos
- ❌ Wall of text
- ❌ Pricing as main focus on landing page
- ❌ Too many sections (max 8-10)
- ❌ Slow loading images
